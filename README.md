# Οδοιπορικό

Προσωπική εφαρμογή ταξιδιών: χάρτης με pin, ημερολόγιο, εμπειρίες, καρτ ποστάλ και συνομιλία για προτάσεις.
Στατικά αρχεία, χωρίς build. Τα δεδομένα μένουν στη συσκευή (IndexedDB).

## Αρχεία
- `index.html`, `style.css`, `app.js`: η εφαρμογή
- `sw.js`, `manifest.webmanifest`, `icons/`: λειτουργία offline και εγκατάσταση στο κινητό

## Ανάρτηση στο GitHub Pages
1. Settings → Pages → Source: Deploy from a branch → Branch: `main`, φάκελος `/ (root)`.
2. Η διεύθυνση θα είναι `https://<χρήστης>.github.io/<repo>/`.

## Εγκατάσταση στο κινητό
- Android (Chrome): μενού ⋮ → Προσθήκη στην αρχική οθόνη.
- iPhone (Safari): Κοινοποίηση → Προσθήκη στην οθόνη Αφετηρίας.

## Συνομιλία
Στις Ρυθμίσεις βάζεις το δικό σου κλειδί Anthropic API. Αποθηκεύεται μόνο στη συσκευή.

## Αντίγραφο ασφαλείας
Ρυθμίσεις → Κάνε αντίγραφο. Τα δεδομένα χάνονται αν σβηστούν τα δεδομένα του browser, γι' αυτό κράτα αντίγραφο.
